# Crime City

Crime City is the base game that Crime City Rewritten is based on. This folder only contains Crime City, and Crime City reverse engineered data. Crime City Rewritten will be in another directory. The game is considered abandonware, as it has not been functional for over a decade, and no updates have been produced in over a decade.

## Crime City Version History

### V9.3.0 (Android)

Only version known to this project. Since the servers are no longer functional, this game will need to be reverse-engineered, in a similar way to how [:octocat: `Katten`](https://github.com/knot126/Katten/) works for letting NGMOCO/Plus+ games to work. Also note that this version doesn't launch at all on Android 10.x or higher (I feel it wouldn't work on Android 7.x, 8.x, or 8.x either, but I haven't tested)

Extracted using an APK backup tool, game never played on this installation. Originally came in an `.apk+` file, which is too large to upload directly (it is over 40 megabytes in size)
